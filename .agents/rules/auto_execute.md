# Auto Command Execution Policy

- **Direct Execution**: Always execute all commands, builds, test scripts, local servers, and file modifications directly and proactively.
- **No Confirmation Prompts**: Do not ask the user for permission before running safe development and operational commands in the workspace.
- **Autonomous Resolution**: When tasks require building, testing, restarting services, or running verification commands, run them immediately using available tools.
